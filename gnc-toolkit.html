GNC Toolkit

An ongoing personal project to close the gap between control theory and working code — the fastest way I've found to actually learn Guidance, Navigation & Control.

Built so far

  • PID tuner — interactively explore how proportional / integral / derivative gains shape a system's step response and stability.
  • Hohmann transfer calculator — two-burn transfer orbits and Δv budgets between circular orbits.

Next

Porting the core into C++ and building a simulation loop that grows from 1-DOF toward a fuller flight / attitude model — closing my biggest pre-master gap: production-grade C++ and Python for GNC.

Why

Turning equations I've only seen on paper into things I can run, test and break. Understanding the theory isn't enough for GNC work — you have to be able to build it.
