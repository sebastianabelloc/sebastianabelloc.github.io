Simulator Session Manager

Internal tool for the A400M full-flight simulator that standardizes the preparation of each test session.

What it does

Generates a session preparation checklist with 7 categories across 3 linked sheets, written in Python with openpyxl, including formulas and conditional formatting. It covers the configuration, deployment and verification steps the simulator needs before a certification test session.

Why

Simulator sessions are scheduled and shared, so a configuration error can cost test time. A single standard checklist makes the preparation the same every time and leaves a record of what was checked before each session.
